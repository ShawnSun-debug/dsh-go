## 踩过的操作坑（省下一轮摸索）

- **git 要带 `-c safe.directory=<绝对路径>`**，否则因 Windows 所有权判定直接拒绝操作。
  我第一次提交**静默失败**（没报错、没提交），就是漏了这个。
- **PowerShell heredoc 管道进 `wsl bash` 会带 CR**，最后一行命令会报 `$'\r': command not found`。
  写法：`($bash -replace "`r","") | wsl -d Ubuntu-24.04 -- bash -l`。
- **WSL 里 flutter 以 root 跑**会打一行警告，不影响结果。
- 首次编译在 `/mnt/c`（NTFS 挂载）上很慢，**不要中断重来**，同一个进程会自己跑完。
- `--update-goldens` 用完必须**不带该参数复跑一次**才算通过；`--name` 要确认真的匹配到目标测试，零项不算通过。
